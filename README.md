## 메뉴 수정 방법

1. images 폴더에서 기존 메뉴 이미지를 같은 파일명으로 교체한다.
2. GitHub 저장소에 업로드한다.
3. Commit 한다.
4. 약 1분 후 GitHub Pages에 자동 반영된다.
